1. Business Understanding

Tujuan

Tujuan dari tugas ini adalah untuk mengetahui kondisi kualitas udara di Kabupaten Sumenep berdasarkan data beberapa polutan selama satu tahun.

Permasalahan

Kualitas udara dapat mengalami perubahan dari waktu ke waktu. Oleh karena itu, diperlukan data untuk melihat bagaimana perubahan konsentrasi polutan selama periode pengamatan.

Pertanyaan yang Ingin Dijawab

  • Bagaimana perubahan konsentrasi polutan dari waktu ke waktu?
  • Kapan terjadi nilai polutan yang tinggi?
  • Apakah terdapat nilai yang terlihat tidak biasa?
  • Bagaimana pola polutan selama satu tahun?

2. Data Understanding

Sumber Data

Data kualitas udara diperoleh dari Open-Meteo.

Data dicatat setiap satu jam pada satu titik koordinat di wilayah Kabupaten Sumenep.

Periode Data

Data yang digunakan mencakup periode:

1 September 2025 - 31 Agustus 2026

Total terdapat 365 hari atau 8.760 pengamatan per jam.

Koordinat Data

Titik koordinat yang digunakan adalah:

Latitude: -7.000000

Longitude: 113.899994

Parameter Polutan

PM2.5

PM2.5 merupakan partikel udara yang memiliki ukuran sangat kecil, sekitar 2,5 mikrometer atau lebih kecil.

Sumbernya dapat berasal dari kendaraan, pembakaran, debu, dan aktivitas industri.

Satuan: μg/m³

PM10

PM10 merupakan partikulat udara dengan ukuran sekitar 10 mikrometer atau lebih kecil.

Sumbernya dapat berasal dari debu, tanah, jalan, konstruksi, dan pembakaran.

Satuan: μg/m³

CO₂

CO₂ atau karbon dioksida merupakan gas yang terdapat di atmosfer.

Salah satu sumber CO₂ dari aktivitas manusia adalah pembakaran bahan bakar.

Satuan: ppm

NO₂

NO₂ atau nitrogen dioksida merupakan gas yang dapat dihasilkan dari proses pembakaran.

Sumbernya dapat berasal dari kendaraan bermotor dan aktivitas industri.

Satuan: μg/m³

Apakah Ada Data Aneh?

Pada dataset terdapat beberapa nilai yang secara statistik terlihat cukup tinggi dibandingkan dengan sebagian besar data.

Nilai tersebut belum tentu merupakan kesalahan. Pada data lingkungan, perubahan nilai dapat terjadi karena perubahan kondisi lingkungan maupun aktivitas manusia.

Oleh karena itu, nilai yang tinggi perlu diperiksa lebih lanjut berdasarkan waktu terjadinya dan kondisi wilayah.

Eksplorasi dan Analisis Data

Setelah data kualitas udara dikumpulkan dan dilakukan eksplorasi awal, data selanjutnya disimpan ke dalam database PostgreSQL menggunakan Aiven. Tahap ini dilakukan agar data yang sudah dikumpulkan dapat disimpan secara terstruktur dan dapat diakses kembali menggunakan aplikasi pengolahan data.

Alur Pengolahan Data

Proses pengolahan data pada tugas ini dilakukan melalui beberapa tahap, mulai dari dataset CSV sampai data dianalisis menggunakan KNIME. Secara umum alurnya adalah:

Dataset CSV → PostgreSQL Aiven → PostgreSQL Connector → DB Table Selector → DB Reader → Statistics

Alur tersebut menunjukkan bahwa data tidak langsung dianalisis di KNIME, tetapi terlebih dahulu disimpan dalam database PostgreSQL pada Aiven. KNIME kemudian digunakan untuk mengambil data dari database dan melakukan analisis statistik.

1. Penyimpanan Data pada PostgreSQL Aiven

Dataset kualitas udara yang sebelumnya telah disiapkan dalam bentuk CSV dimasukkan ke dalam database PostgreSQL yang disediakan oleh Aiven. Database digunakan sebagai tempat penyimpanan data agar data dapat dikelola dan diakses melalui koneksi database.

Pada database tersebut dibuat tabel dengan nama air_quality. Tabel ini berisi data waktu pengamatan dan empat parameter kualitas udara, yaitu PM10, PM2.5, karbon dioksida (CO₂), dan nitrogen dioksida (NO₂).

Data yang dimasukkan berjumlah 8.760 baris. Jumlah tersebut berasal dari pengamatan setiap satu jam selama 365 hari, sehingga 365 × 24 menghasilkan 8.760 pengamatan.

Struktur tabel air_quality:
  • time → waktu pengamatan
  • pm10 → konsentrasi PM10
  • pm2_5 → konsentrasi PM2.5
  • carbon_dioxide → konsentrasi CO₂
  • nitrogen_dioxide → konsentrasi NO₂

Gambar: Penyimpanan data kualitas udara pada PostgreSQL Aiven.

2. Menghubungkan Aiven dengan KNIME

Setelah data berhasil disimpan pada PostgreSQL Aiven, langkah berikutnya adalah menghubungkan database tersebut dengan KNIME Analytics Platform. KNIME digunakan untuk membaca data dari database dan melakukan analisis terhadap data yang sudah tersimpan.

Koneksi dilakukan menggunakan node PostgreSQL Connector. Node ini berfungsi sebagai penghubung antara KNIME dengan database PostgreSQL yang berada pada Aiven. Informasi koneksi yang digunakan meliputi hostname, port, nama database, username, dan password.

Karena database PostgreSQL pada Aiven menggunakan koneksi yang aman, parameter sslmode=require digunakan pada pengaturan JDBC agar KNIME dapat melakukan koneksi ke database.

3. Memilih Tabel dengan DB Table Selector

Setelah koneksi berhasil, node DB Table Selector digunakan untuk menentukan tabel yang akan digunakan dari database. Pada tahap ini tabel air_quality dipilih dari schema public.

Pemilihan tabel dilakukan agar KNIME hanya mengambil data yang diperlukan untuk tugas analisis kualitas udara.

4. Membaca Data dengan DB Reader

Setelah tabel dipilih, node DB Reader digunakan untuk membaca isi tabel tersebut. Data dari PostgreSQL kemudian diteruskan ke proses berikutnya di dalam workflow KNIME.

Pada tahap ini data yang dibaca terdiri dari 8.760 pengamatan dengan lima kolom, yaitu time, pm10, pm2_5, carbon_dioxide, dan nitrogen_dioxide.

5. Analisis Menggunakan Statistics

Setelah data berhasil dibaca oleh KNIME, node Statistics digunakan untuk melihat ringkasan statistik dari data. Analisis ini membantu mengetahui karakteristik dasar dari setiap parameter polutan sebelum melihat pola perubahan data melalui grafik time series.

Statistik yang ditampilkan oleh node Statistics dapat digunakan untuk melihat ukuran pemusatan, penyebaran, serta nilai terendah dan tertinggi dari data. Contohnya adalah jumlah data, nilai minimum, maksimum, rata-rata, median, standar deviasi, dan statistik lain yang tersedia pada output node.

Gambar: Workflow pengolahan data dari PostgreSQL Aiven sampai Statistics pada KNIME.

Penjelasan Statistik

  1. Count menunjukkan jumlah data yang berhasil dianalisis. Pada dataset ini terdapat 8.760 pengamatan untuk setiap parameter.
  2. Mean merupakan nilai rata-rata dari seluruh data. Mean digunakan untuk mengetahui nilai konsentrasi rata-rata suatu polutan selama periode pengamatan.
  3. Median merupakan nilai tengah setelah data diurutkan. Median dapat digunakan untuk melihat nilai tengah data dan membantu membandingkannya dengan nilai rata-rata.
  4. Minimum menunjukkan nilai paling rendah yang ditemukan pada masing-masing parameter selama periode pengamatan.
  5. Maximum menunjukkan nilai paling tinggi yang ditemukan pada masing-masing parameter selama periode pengamatan.
  6. Standard Deviation menunjukkan seberapa besar penyebaran nilai data terhadap nilai rata-ratanya. Semakin besar nilai standar deviasi, semakin besar variasi data terhadap rata-ratanya.
Kesimpulan dari Tahap Pengolahan Data

Pada tahap ini, data kualitas udara yang sebelumnya tersedia dalam bentuk dataset CSV disimpan terlebih dahulu pada PostgreSQL Aiven. Database tersebut kemudian dihubungkan dengan KNIME menggunakan PostgreSQL Connector. Tabel air_quality dipilih menggunakan DB Table Selector dan datanya dibaca menggunakan DB Reader.

Setelah data berhasil dibaca, node Statistics digunakan untuk memperoleh ringkasan statistik dari parameter PM10, PM2.5, CO₂, dan NO₂. Hasil statistik tersebut digunakan untuk memahami karakteristik data secara numerik sebelum data dianalisis lebih lanjut menggunakan visualisasi time series.

5. Time Series

Time series digunakan untuk melihat perubahan nilai polutan berdasarkan waktu.

Data yang digunakan memiliki interval setiap satu jam selama satu tahun.

Cara membaca grafik

Sumbu horizontal menunjukkan waktu pengamatan, sedangkan sumbu vertikal menunjukkan nilai konsentrasi polutan.

Dari grafik dapat dilihat bahwa nilai polutan mengalami perubahan selama periode pengamatan.

Beberapa waktu menunjukkan adanya kenaikan nilai yang cukup tinggi. Kondisi tersebut dapat diperiksa kembali menggunakan data asli.

6. Kesimpulan

  1. Dataset memiliki sebanyak 8.760 observasi dengan interval waktu setiap satu jam.
  2. Data mencakup periode 1 September 2025 sampai 31 Agustus 2026.
  3. Terdapat empat parameter yang dianalisis, yaitu PM2.5, PM10, CO₂, dan NO₂.
  4. Hasil pemeriksaan awal tidak menemukan missing value, duplikasi waktu, dan nilai negatif.
  5. Terdapat beberapa nilai yang termasuk outlier berdasarkan metode IQR.
  6. Nilai outlier tidak langsung dianggap sebagai kesalahan karena dapat terjadi akibat perubahan kondisi lingkungan.
  7. Grafik time series digunakan untuk melihat perubahan konsentrasi polutan dari waktu ke waktu.
